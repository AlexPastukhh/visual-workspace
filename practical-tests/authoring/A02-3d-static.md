# A02 — 3D static asset: sci-fi crate

**UC:** VIS-001 + VIS-004. **Work area:** Workfiles run output/A02/ only.

## Brief
Create an original low-poly sci-fi supply crate in Blender, about 1.2×0.8×0.8 Godot units, with dark-blue body, orange lid seam and a visible clasp on its front. Top, front and side must be distinguishable. Keep it upright on a floor, without floating parts. Do not submit an existing beacon or robot.

## Deliver and check
Editable .blend source, importable .glb, standalone Godot 4.7 preview, actual front/perspective and side runtime screenshots, brief and review. Check dimensions/orientation, geometry/material imports, clasp visibility, framing, intersections and missing textures. Animation not required. Report commands/results.
