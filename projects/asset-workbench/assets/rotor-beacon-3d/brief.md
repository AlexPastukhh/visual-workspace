# Rotating 3D beacon

An editable turquoise upright tower supports an asymmetric amber rotor.
The Sweep clip turns the rotor once about the vertical axis over two seconds and loops.
The tower remains stationary and upright. There should be no detached pieces or pose reset
inside the cycle; the two-second loop returns to the starting orientation.

Check the full sequence and four views. The rotor direction must change while the tower
stays fixed. This example exercises the shared 3D stage, ordinary clip sampler and framing.
The tower has no gameplay-facing requirement.
