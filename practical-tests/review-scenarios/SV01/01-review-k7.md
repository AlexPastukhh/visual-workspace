# SV01.01 — 2D-развороты: первая часть

ВАЖНО — ИНСТРУМЕНТЫ: этот read-only Visual QA тест проходит только через Fortis Repo и реальные кадры из Visual Workspace. НЕ создавай, не изменяй и не «улучшай» изображений с помощью ChatGPT image_gen или любых генераторов AI-картинок; не подменяй исходные PNG синтетическими кадрами. Только проверяй назначенные fixtures по собственным brief.

Работай с подключением Fortis Repo. Это **первая часть одного многошагового сценария**: используй НОВЫЙ чат и не открывай продолжение заранее. Перед чтением README получи реальное UTC T0 из часов контейнера. Затем прочитай /workspace/repo/README.md, /workspace/repo/AGENTS.md, действующий /workspace/repo/Repos/visual-workspace/README.md, применимые UC-VIS-004/006/008, WORKFLOW.md, правила Visual QA и practical-tests/TIMING.md. После bootstrap зафиксируй T1.
Работай с принятым main и исходными fixtures ТОЛЬКО НА ЧТЕНИЕ. Не создавай task worktree, не исправляй анимации, не публикуй в GitHub, не вызывай publish_visual_review и owner ASK. Не читай _evaluator/, старые ревью, отчёты из чужих Workfiles и другие тестовые промпты. Не предполагай заранее, что неисправных случаев фиксированное число.
Для всего сценария создай одну уникальную папку в /workspace/repo/Workfiles/visual-workspace-practical-tests/runs/<run-id>/. Для каждого назначенного клипа прочитай brief.md и capture.json, реально просмотри contact_sheet.png и ВСЕ оригинальные полноразмерные PNG по порядку. Особое внимание смежным кадрам и границам движения: метаданные и контактный лист без оригиналов недостаточны.
По каждому клипу дай собственный PASS/FAIL/UNCERTAIN, проверяемые наблюдения, точные frame/time, уверенность и границы доказательств. Не выдумывай дефекты. Сохрани отдельный review-<case>.md и действительный timing.md. Замерь UTC T2 после briefs/плана, T3 при первом реально просмотренном полноразмерном PNG, T4 после всех назначенных на эту часть клипов, T5 после проверки отчётов; вычисли T3−T0 и T5−T0. По каждому клипу — начало/конец просмотра и число реально открытых кадров. Отметь, если время не измерено; tool time не равно UI latency.
После сдачи первой части остановись и ожидай **другое пользовательское сообщение в этом же чате**. Не выполняй заранее второй этап и не раскрывай будущие кейсы. Первая часть сама по себе не является PASS целого сценария.

**Текущая задача:** Проверь только clip-k7: один 2D-разворот двух самолётов. Проверь плавность разворота, сохранение крыльев и силуэтов, дорожек и непрерывности по его собственному brief. Исходные 24 кадра и контактный лист реально просмотри. Сохрани review-clip-k7.md, timing.md и сообщи независимый вывод; никакие другие клипы пока не анализируй.

После выполнения именно этого этапа: в своей уже созданной папке /workspace/repo/Workfiles/visual-workspace-practical-tests/runs/<runId>/ сохрани reports/units/SV01.01/submission.md — маршрутный указатель для независимой проверки (unitId=SV01.01, runId, исходный промпт, task worktree и полный source SHA или N/A, GitHub Issue/revision/comment или N/A, реальные пути PNG/QA/отчётов, timing file, итог PASS/PARTIAL/BLOCKED и ограничения). Это не самостоятельная оценка, не копия evaluator scorecard; не открывай соседний 01-evaluate.md или _evaluator/. Если такого файла не удалось сохранить, явно укажи в отчёте точный путь к уже записанным доказательствам.
