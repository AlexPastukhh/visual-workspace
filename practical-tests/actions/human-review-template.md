# Человеческая визуальная оценка — шаблон для одного unit

Это **первый** независимый этап ревью. Создать файл
`evaluations/<runId>/<unitId>/human-review.md` разрешено только после
реального просмотра человеком и **его собственного** явного отзыва.
Технической оценки чата в этот момент **ещё нет**; не требовать, не
подставлять и не выдумывать будущие `decision.md` или его вердикт.

- `actionId`: фактическое значение
- `variantId`: фактическое значение
- `runId`: фактическое значение
- `unitId`: фактическое значение
- `definition_git_sha`: версия действовавшего `visual-testing.yaml`
- `human_review_required`: `true` (по закреплённой версии варианта)
- `reviewer`: обозначение реально оценившего человека
- `review_time_utc`: точное время или `UNKNOWN`
- `human_feedback_source`: ссылка/точная запись **реального** сообщения человека
- `viewed_evidence`: действительно просмотренные PNG/видео/кадры/ракурсы и их версии
- `reference_compared`: путь и SHA256 референса или `N/A`
- `human_verdict`: `ACCEPTED` / `CHANGES_REQUESTED` / `INCONCLUSIVE`
- `visual_findings`: конкретные наблюдения с кадрами, зонами, объектами и severity, если заявлены
- `visual_aspects_already_judged`: перечень аспектов, которые **чат не будет оценивать повторно**
- `not_viewed_or_unknown`: что человек не увидел или не может оценить
- `requested_changes`: конкретные изменения при необходимости, иначе `N/A`

Если известен лишь неопределённый отзыв, сохраняй его как есть и отмечай
`not_viewed_or_unknown`, не выдумывай детали. Если для анимации человек видел
только неподвижный PNG — **не** оформляй полное принятие её движения.
Отзыв сохраняется неизменным; дальнейшая правка — отдельная ревизия.
