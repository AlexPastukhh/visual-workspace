Работай через подключение Fortis Repo. **В самом начале, до чтения README**, получи точное UTC-время из часов контейнера (например, `date -u +"%Y-%m-%dT%H:%M:%S.%NZ"`) и запиши его как T0. Не оценивай длительность на глаз.

Сначала прочитай README Visual Workspace:
`/workspace/repo/Repos/visual-workspace/README.md`
Выполни описанный там bootstrap, прочитай необходимые для задачи правила и юзкейсы Visual QA. После bootstrap запиши UTC T1. Прочитай `practical-tests/TIMING.md` — там определены остальные отметки T2–T5.

**Твоя задача — проверить два независимых примера в одном чате:** `clip-m4` (2D-анимация) и `clip-r2` (3D-анимация) из `/workspace/repo/Repos/visual-workspace/practical-tests/visual/cases/`. Это практическая проверка способности разбираться в разных визуальных работах после одного bootstrap.

Для каждого случая прочитай свой `brief.md` и `capture.json`, затем реально просмотри `contact_sheet.png` и оригинальные полноразмерные PNG в хронологическом порядке. Проверяй переходы между соседними кадрами: возможны кратковременные ошибки, которые теряются на контактном листе. Не выводи PASS/FAIL из метаданных. Не переноси выводы одного примера на другой и не предполагай, что ошибка обязана присутствовать.

Для каждого клипа отдельно запиши: степень соответствия письменному brief, PASS/FAIL/UNCERTAIN, наблюдаемые факты, точные номера кадров/время, уверенность, непроверенные гипотезы и реально просмотренные изображения. Сохрани `review-clip-m4.md`, `review-clip-r2.md` и `summary.md` в своей новой уникальной папке под `/workspace/repo/Workfiles/visual-workspace-practical-tests/runs/`. Источники и репозиторий не меняй. Не читай `practical-tests/_evaluator/`, прошлые отчёты и чужие заключения.

В `timing.md` сохрани фактические UTC-метки T0 (перед README), T1 (после bootstrap), T2 (после чтения обоих briefs), T3 (после первого реально просмотренного полноразмерного PNG), T4 (после завершения просмотра обоих клипов), T5 (после проверки готовых отчётов перед финальным ответом). Посчитай секунды между этапами и **общее время T5−T0 для полного запуска**, включая ожидание инструментов, подготовку, проверку и оформление. Отдельно запиши начало/конец просмотра каждого клипа. Если доступ к часам недоступен — честно отметь это, не выдумывай цифры.

В финальном ответе сообщи вывод по обоим клипам, полную измеренную длительность, разбивку и путь к отчётам. Действуй самостоятельно по workflow Visual Workspace.

не вызывай `publish_visual_review` и не создавай owner ASK без отдельного
