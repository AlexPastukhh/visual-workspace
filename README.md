# visual-workspace

Приватное пространство для просмотра визуальных результатов работы: изображений,
рендеров 3D, анимаций и видео. Цель — дать владельцу **одну проверенную ссылку
GitHub** с предпросмотром, контекстом и результатами QA, а не просто путь к файлу
в Docker.

- [Use Cases — краткий реестр](docs/use-cases/README.md)
- [UC-VIS-001 — Создать медиа, опубликовать превью в GitHub и передать ссылку](docs/use-cases/media-github-review.md)
- [Backlog поддерживаемых форматов и публикации](docs/BACKLOG-IMPROVEMENTS.md)

**Текущая автоматизация:** Fortis Gateway поддерживает owner-ASK публикацию
1–5 **PNG** в приватный GitHub Issue этого репозитория. Фактический Issue URL
можно передавать только после подтверждённого `EXECUTED` и readback. Для
видео и исходных 3D-файлов автоматический upload/просмотр пока не подтверждён;
не объявлять ссылку на PNG-превью ссылкой на сам видео/3D-артефакт.
