# A06 — Two independent orders in one request

**UC:** VIS-007 and VIS-001 + VIS-004 for each unit. **Work area:** Workfiles run output/A06/ only.

## Brief
Create two independent units:
1. A06-crystal: static 2D collectible key icon, exactly 48×48 pixels, green/gold, with alpha and readable game-size Godot preview.
2. A06-column: static 3D stone waypoint column about 2 units high, glowing blue inset, distinct base, Blender-editable source and Godot preview.
Game integration beyond preview is not required.

## Deliver and check
Give each unit its own brief, editable source, export, Godot preview, screenshots and import/visual verdict. Use separate output/A06/crystal/ and output/A06/column/ subdirectories. If multiple agents work, split exclusive ownership; separate projects avoid shared-scene collisions. No repository edits, and do not mistake one completed unit for the whole order.
