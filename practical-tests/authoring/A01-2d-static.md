**UC:** VIS-001 + VIS-004. **Work area:** assigned Workfiles run's output/A01/ only.

## Brief

Show in a standalone Godot 4.7 scene at approximately 64 display pixels in a 1280×720 viewport. Do not copy the existing beacon.

Keep source, export and QA output separate. Verify alpha, visible core/rim, framing and import. No animation required. Report test commands and remaining visual weaknesses. Never edit the repository fixtures.
