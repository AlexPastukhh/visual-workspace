# Visual MVP (historical assets)

This folder keeps editable Krita (`.kra` / `.ora`) and Blender (`.blend`) samples, helper scripts, and PNG previews from an earlier visual-workflow experiment.

It is a reference project, not the active animation workflow. Use [Game Animation Lab](../game-animation-mvp/README.md) for the current Godot 2D/3D pipeline.

Blender 5.2.3 is available through the repository launcher; see [Blender runtime](../../tools/BLENDER_RUNTIME.md). Krita execution in the current Fortis Repo container is not established.
