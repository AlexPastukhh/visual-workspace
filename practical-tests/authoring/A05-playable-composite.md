# A05 — Complete commission: asset, animation and playable game

**UC:** VIS-001 → VIS-002 → VIS-003 → VIS-004 → VIS-005. **Work area:** Workfiles run output/A05/ only.

## Brief
Create a small original 2D Godot 4.7 game. A controllable robot orb moves left/right (A/D or arrows), jumps (Space), and activates a floor switch (E). The closed gate blocks the exit until the switch is activated. The orb has editable source and visible Idle, Move and Jump animations. The gate visibly opens before the exit is reachable. No autoplay or teleports as substitutes for gameplay input.

## Deliver and check
Standalone Godot project, original editable source/exported art, repeatable input-driven test, game-size screenshots for start, jump, blocked gate, activation, opened gate and reached exit, plus brief and visual review. Verify collisions, out-of-range activation refusal, state transitions, movement and restart. Existing Animation Relay is read-only reference, not a finished submission.
