## Источники, воспроизводимость и выбор

В работе только [четыре закреплённых референсных PNG](references/PROVENANCE.md), с URL оригинала, заявленной CC0-лицензией, Godot-методом перевода SVG→PNG и точными SHA256. Исполнитель не получает исходный оригинальный SVG/AI для механического копирования, а создаёт собственный редактируемый ассет. Текстовые запреты — не sandbox безопасности: оценщик при доступности сверяет tool trace/source provenance. Ни один reference PNG не произведён через генеративный image_gen.

[Гибкий каталог](SCENARIO-CATALOG.md) позволяет искать сценарии по нескольким независимым признакам: формат, сложность, операции, число источников, fidelity, точечные изменения, время. Это НЕ жёсткая классификация «обычные/сложные». Выбирай под конкретную оптимизацию один нужный сценарий или малую целевую выборку с фиксированным контролем; нет необходимости каждый раз запускать все четыре или все SC/SV.

[Маршрут результата](../UNIT-SUBMISSION-CONTRACT.md): runs/<runId>/reports/units/<unitId>/submission.md. Независимое заключение: evaluations/<runId>/<unitId>/decision.md. Для дополнительных не запланированных исправлений создавать парный промпт по [unit-gates](../_evaluator/unit-gates/author-unplanned-pair.md); новый источник и фактическая GitHub ревизия сохраняются, плохая первая попытка не затирается.

Все RS сценарии находятся в состоянии NOT RUN — подготовленный тест не равен выполненному. Исходные SC/SV/C/V и их QA/evaluator файлы не изменены.
