# VT12 / SV02.02 — независимый evaluator: сравнение с эталоном, не новый поиск

НОВЫЙ чат-оценщик с Fortis Repo, не чат-исполнитель. Получи от владельца фактические `actionId=VT12`, `variantId=existing-jumps-and-walk`, `unitId=SV02.02` и `runId`. Идентификаторы должны соответствовать реальному пути `runs/<runId>/reports/units/SV02.02/submission.md`. При отсутствии однозначной привязки возвращай `INCONCLUSIVE`, не подставляй последний run и не придумывай отчёт.

**Главное правило:** прочитай полностью `practical-tests/actions/DEFECT-SCORING.md` и используй его вместо самостоятельного распознавания дефектов. **НЕ** пытайся анализировать изображения/анимацию второй раз с целью самому найти дефект. Задача оценщика — проверить, **насколько точно испытуемый чат распознал наличие/отсутствие дефектов** на назначенных ему входах; он сравнивает замороженные утверждения испытуемого с закрытым эталоном только в разрешённый момент. Не модифицируй оригинальные кадры, Workfiles runner, source, ключ или GitHub. image_gen и любая AI-генерация запрещены.

Исполнительское задание этой части — `practical-tests/review-scenarios/SV02/02-review-walk.md` (не выполняй его сам, используй **только как критерии для оценки**); historical evaluator `practical-tests/review-scenarios/SV02/02-evaluate.md` сохраняется как исходная версия, но новый **Action-режим** определяется настоящим prompt и `DEFECT-SCORING.md`.

**Это завершающий gate после второй части**: сначала проверь замороженность ответов обеих частей, затем (и только затем) открой evaluator-only `answer-key.json` и вычисли rubric по всем кейсам сценария; сохранить `evaluations/<runId>/defect-score.md`. Не возвращай точные метки, локализацию или seeded details в чат исполнителя.

В отдельном evaluator-owned `evaluations/<runId>/SV02.02/decision.md` по `practical-tests/_evaluator/unit-gates/decision-template.md` запиши только собственную проверку идентичности, достоверности и процесса исполнения, с пометкой `assessment_scope: PROCESS_GATE_ONLY` (до финальной части) либо `PROCESS_GATE_AND_SCENARIO_SCORE` (после финальной). Вывод о точности поиска — только по подтверждённому закрытому ключу после завершения всей последовательности, не через самостоятельное художественное или покадровое распознавание. Не раскрывай ответ испытуемому; верни путь к результату и можно ли продолжать сценарий.
