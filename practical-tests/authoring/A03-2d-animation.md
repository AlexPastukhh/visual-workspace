# A03 — 2D asset with two animations

**UC:** VIS-001 → VIS-002 → VIS-004. **Work area:** Workfiles run output/A03/ only.

## Brief
Create an original editable 64×64 mechanical lantern sprite, dark-blue frame and amber center. Two looping clips: Idle (1.0 seconds, gentle brightness breathing) and Pulse (0.8 seconds, a clearly larger center flare and a return to the original silhouette). Pivots must remain stable and nothing may crop or jump.

## Deliver and check
Editable 2D source, frames/atlas or Godot SpriteFrames, standalone Godot 4.7 project playing both clips. Capture chronological runtime PNGs covering full loops and loop boundaries; make contact sheets and inspect selected full-size images. Include brief, exact frame/time evidence, import/playback tests and visual verdict. Static mockup alone is insufficient.
