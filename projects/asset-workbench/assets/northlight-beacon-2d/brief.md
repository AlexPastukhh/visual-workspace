# Northlight navigation beacon — static 2D icon

**Purpose:** a small, clear navigation-console emblem for the first real UC-VIS-009 owner review and private GitHub PNG Issue E2E.

**Scope:** editable 256×256 SVG vector (transparent corners), imported in Godot Asset Workbench as a static 2D sprite. No animation, interaction or gameplay integration is claimed. Scene preview uses the maintained neutral 2D QA stage; this is an inspection asset, not an exported game.

**Design:** crisp dark blue octagonal badge, luminous teal compass rose with clearly visible cardinal ticks and one amber north pointer. The dark base should remain legible against the QA stage; ring, needle, core and outline must stay distinct. No external images/fonts.

**Acceptance:** SVG loads in Godot; whole badge is visible and centred in a real 1280×720 capture; no clipping, missing facets or import errors; transparent corners are preserved. No motion is expected across the six QA frames. Review visible appearance of the actual PNG, not the SVG text alone.

**Owner review:** first production-like preview will be published with owner ASK through the existing `publish_visual_review` PNG-only Gateway method. The GitHub Issue is for visual feedback, not proof that the source has been merged or run on Windows. Preserve the editable SVG and QA config under the task's exact source SHA before publishing.
